**Wave** 3 · **Spec** all · **Starts** after G3 (real data in the app)

## Goal

Look at the finished app as an executive judge would, find what's wrong or unclear before they do, and write the 2-minute demo script and the submission text.

## Owns

- `reports/launch-review.md`
- `docs/demo-script.md`, `docs/submission.md`

## Tasks

- [ ] Review the running app (`make app`) and the docs against SPEC and CLAUDE.md: wrong or unsupported numbers, jargon, claims stronger than the evidence, missing sources, broken screens at phone width, anything that contradicts the timing test. Classify each finding as blocker / should-fix / nit, naming the owning lane and the file.
- [ ] Check five numbers end to end: pick them in the app, trace each to `app/data/` and to the code that made it.
- [ ] `docs/demo-script.md`: ≤ 2 minutes spoken (~260 words), screen-by-screen, following Data → model → output → decision → feedback, with the honest limits in one line.
- [ ] `docs/submission.md`: project title, problem statement, solution, technical approach (baseline + ours), results, limits, data credits — ready to paste into iKompete.
